\section*{Mission}
\sectionmark{Mission}

\textit{What the Club does and aims to achieve each year}

\vspace{0.5cm}

The mission of the NCE IT Club defines what we do on a yearly basis, our concrete activities and goals that apply during each President's tenure and every academic year.

\subsection*{1. Organize Regular Technical Events}

Each academic year, the Club shall organize:

\begin{itemize}[leftmargin=2em, itemsep=0.3em]
    \item \textbf{Minimum 2 Bootcamps} - Intensive training on technologies like Python, web development, etc.
    \item \textbf{Minimum 2 Workshops} - Hands on sessions on various technical topics
    \item \textbf{Minimum 2 Competitions} - Programming contests or technical challenges
    \item \textbf{Minimum 1 Seminar/Tech Talk} - Sessions with industry experts or alumni
\end{itemize}

These events are designed to give students practical, hands on experience with technologies and skills that regular courses may not cover.

\subsection*{2. Complete One Club Project Annually}

Each year, the Club shall complete at least one project that:

\begin{itemize}[leftmargin=2em, itemsep=0.3em]
    \item Addresses a real need (for the campus, club, or community)
    \item Involves club members in actual development work
    \item Demonstrates our technical capabilities
    \item Provides practical experience to participating members
\end{itemize}

Projects could include apps for campus use, tools for the club itself, or solutions for local needs.

\subsection*{3. Build Technical Skills}

Through all our activities, we focus on helping students develop:

\begin{itemize}[leftmargin=2em, itemsep=0.3em]
    \item Programming and coding skills
    \item Web development and modern technologies
    \item Problem solving abilities
    \item Understanding of industry tools and practices
\end{itemize}

\subsection*{4. Develop Soft Skills}

Beyond technical knowledge, we help members build:

\begin{itemize}[leftmargin=2em, itemsep=0.3em]
    \item Leadership and teamwork abilities
    \item Communication and presentation skills
    \item Project management experience
    \item Professional conduct and work ethics
\end{itemize}

\subsection*{5. Connect with Industry}

We work to bridge the gap between academic learning and industry practice by:

\begin{itemize}[leftmargin=2em, itemsep=0.3em]
    \item Inviting industry professionals as guest speakers
    \item Arranging mentorship opportunities when possible
    \item Bringing in trainers from IT training institutes
    \item Sharing insights about current tech trends and career paths
\end{itemize}

\subsection*{6. Build Community}

We create a space where:

\begin{itemize}[leftmargin=2em, itemsep=0.3em]
    \item Technology enthusiasts can connect and collaborate
    \item Students can learn from each other
    \item Members support one another's growth
    \item Everyone contributes to a positive tech culture on campus
\end{itemize}
